# Golden thread art (drafts)

Midjourney drafts from Taylor, Oct 28, made from the prompts Claude suggested that day. **None of these are in the app.** Each one goes in only after its placement is briefed and approved line by line, alt text included (`docs/VOICE.md`). The app's golden thread colors are `--thread-golden: #D9A12B` and `--thread-golden-glow: #F2C14E` (`app/src/styles/tokens.css`).

| File | What | Status |
