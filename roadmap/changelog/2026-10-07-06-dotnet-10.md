## 2026-10-07 · Moved to .NET 10 before .NET 8 support ends

**Task:** T-219 (from the Oct 2 security review, L8). Nothing a person sees changes.

### What changed

- The API, the data layer, the command-line tool and the tests now run on .NET 10, which is supported until November 2028. .NET 8 stops getting security fixes on Nov 10, 2026.
- The Microsoft packages moved from 8.0 to 10.0, and GitHub builds with the .NET 10 SDK. No package has a known vulnerability.
- One test-setup fix: EF Core 10 kept the app's SQL Server setting next to the tests' SQLite one, so the tests now remove both before adding SQLite.
- `docs/OPERATIONS.md` has a new Runtime section on keeping the Azure stack in step with the build. `docs/CONTINUE.md` now asks for the .NET 10 SDK.

### Why

Taylor chose to switch the Azure setting rather than ship the runtime inside the build (Oct 7), so Azure keeps applying runtime patches.
