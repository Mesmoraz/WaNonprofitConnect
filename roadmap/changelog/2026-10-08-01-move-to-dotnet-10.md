## 2026-10-08 · Move to .NET 10 before .NET 8 support ends

**Task:** T-219, from the security review of 2026-10-02 (L8).

### What changed

- The API, the command-line tool, the data project and the tests now run on .NET 10 (long-term support to November 2028). .NET 8 stops getting security patches on November 10, 2026.
- Entity Framework and the other Microsoft packages are on 10.0. The database model is unchanged: no new migration.
- The test setup that swaps in SQLite also removes Entity Framework's newer options registration. Without that, both databases end up registered (an EF Core 9+ change).
- CI builds with the .NET 10 SDK. The README and CONTINUE.md say .NET 10.
- Azure runs each site on the .NET 10 runtime, switched right before that site gets this build.
